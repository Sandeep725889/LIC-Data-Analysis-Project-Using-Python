LIC Insurance Data Analysis using Python

📌 Project Overview

This project analyzes 5,000 LIC insurance records using Python to identify meaningful patterns and insights related to customers, policies, premiums, and insurance business performance.

The project focuses on data cleaning, exploratory data analysis (EDA), visualization, and business insights using Python and popular data analysis libraries.

🎯 Objectives

- Analyze LIC customer and policy data
- Clean and preprocess the dataset
- Identify trends and patterns in insurance data
- Analyze premium and policy-related information
- Understand customer demographics
- Create meaningful visualizations
- Generate business-oriented insights from the data

🛠️ Tools & Technologies

- Python
- Pandas – Data cleaning and manipulation
- NumPy – Numerical analysis
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Jupyter Notebook

🔍 Key Analysis

The project includes analysis of:

- Customer demographics
- Gender distribution
- Age groups
- Policy types
- Premium analysis
- Policy distribution
- Customer segmentation
- Trends and patterns
- Correlation between important variables

📊 Visualizations

Various charts are created to understand the dataset, including:

- Bar Charts
- Count Plots
- Pie Charts
- Histograms
- Box Plots
- Distribution Plots
- Correlation Heatmap

💡 Business Insights

The analysis helps identify:

- Customer segments with higher representation
- Popular insurance policy categories
- Premium distribution and patterns
- Demographic trends among policyholders
- Areas that can support data-driven insurance decisions
